# LLM-Powered Booking Analytics & QA System

## Overview

This project, developed for the Solvei8 AI/ML Internship Assignment, implements a system using Python and FastAPI to analyze hotel booking data stored in MySQL. It provides insights via a structured Analytics API endpoint (`/analytics`) and enables natural language question answering about the data via a Retrieval-Augmented Generation (RAG) API endpoint (`/ask`). The RAG system uses FAISS for vector storage, Sentence Transformers for embeddings, and Mistral-7B via Ollama for language generation, retrieving context based on pre-aggregated monthly summaries of the booking data.

## Features

* **Analytics API (`POST /analytics`):** Returns pre-defined analytics reports (Revenue Trends, Cancellation Rate, Geo Distribution, Lead Time Stats) calculated via direct SQL queries.
* **Q&A API (`POST /ask`):** Answers natural language questions using a RAG approach based on monthly aggregated summaries of the booking data.
* **Health Check API (`GET /health`):** Checks the status of the database connection. (Bonus feature implemented).

## Setup Instructions

Follow these steps to set up and run the project locally:

1.  **Clone the Repository:**
    ```bash
    git clone <your-repo-url>
    cd <your-repo-name>
    ```

2.  **Create and Activate Python Virtual Environment:**
    ```bash
    # Create venv
    python -m venv venv
    # Activate venv
    # Windows:
    venv\Scripts\activate
    # macOS/Linux:
    source venv/bin/activate
    ```

3.  **Install Dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Download Booking Data:**
    * Download the `hotel_bookings.csv` dataset (e.g., from the Kaggle link provided in the assignment PDF or another source).
    * Place the downloaded `hotel_bookings.csv` file inside the `data/` directory.

5.  **Set Up MySQL Database & Credentials:**
    * Ensure you have a MySQL server running locally.
    * Create a database named `hotel_booking_db`. You can use a MySQL client or command line: `CREATE DATABASE IF NOT EXISTS hotel_booking_db;`
    * **Edit the Python code directly:** You need to manually update the MySQL credentials inside the source code files:
        * Open `app/utils.py`. Locate the `DB_CONFIG` dictionary near the top and modify the `'user'`, `'password'`, `'host'`, and `'port'` values to match your MySQL setup.
        * Open `scripts/create_vector_store.py`. Locate the `MYSQL_DB_CONFIG` dictionary near the top and modify the `'user'`, `'password'`, `'host'`, and `'port'` values to match your MySQL setup.
    * **Ensure the database name** used in these files (`DB_NAME = 'hotel_booking_db'` in `utils.py` and `database='hotel_booking_db'` in `create_vector_store.py`) matches the database you created.

6.  **Load Data into MySQL:**
    * Run the following command *once* from the project root directory (with the virtual environment activated) to create the `bookings` table (if it doesn't exist) and load the data from the CSV file:
        ```bash
        python app/utils.py
        ```
    * Verify in the terminal output that the data insertion was successful.

7.  **Set Up Ollama and Mistral Model:**
    * Download and install Ollama from [https://ollama.com/](https://ollama.com/).
    * Pull the required Mistral model using the command line (this may take time and requires several GB of disk space):
        ```bash
        ollama pull mistral
        ```
    * Ensure the Ollama application/server is running in the background before starting the API. You can check by running `ollama list` in a separate terminal.

8.  **Create Vector Store (FAISS Index & Summaries):**
    * Create the `vector_store/` directory in the project root if it doesn't exist:
        ```bash
        # Windows:
        mkdir vector_store
        # macOS/Linux:
        mkdir -p vector_store
        ```
    * Run the script *once* to fetch aggregated data from MySQL, generate embeddings for the summaries, create the FAISS index, and save the summary texts:
        ```bash
        python scripts/create_vector_store.py
        ```
    * *(Note: This requires MySQL to be running and populated with the correct credentials entered in the script. This step can take 15+ minutes depending on your hardware). Check for `faiss_index.index` and `text_data.pkl` in the `vector_store` directory.*

9.  **Run the API Server:**
    * Ensure Ollama and MySQL services are running.
    * Run the FastAPI application using Uvicorn from the project root directory (with the virtual environment activated):
        ```bash
        uvicorn app.main:app --reload
        ```

10. **Access the API:**
    * The API will be available at `http://127.0.0.1:8000`.
    * Access the interactive documentation (Swagger UI) at `http://127.0.0.1:8000/docs` to explore and test the endpoints.
## Using the API

The API provides the following endpoints, testable via the `/docs` interface:

* **`POST /analytics`**: Returns structured analytics reports calculated via SQL.
    * *Request Body:* None
* **`POST /ask`**: Answers natural language questions using the RAG system (based on monthly aggregated summaries).
    * *Request Body:* `{"query": "Your question here"}`
    * *Example:* `{"query": "What was the cancellation rate in Portugal in August 2016?"}`
* **`GET /health`**: Checks the database connection status.
